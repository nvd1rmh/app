# ابزارهای فرنو الکترونیک (Farno Tools)

اپلیکیشن اندروید **کاملاً آفلاین** برای محاسبات الکترونیک  
طراحی مدرن تیره · راست‌چین · فارسی

---

## ابزارهای موجود

### مقاومت‌ها
- محاسبه رنگ مقاومت (۴ باند)
- مقدار ← رنگ استاندارد E24
- سری و موازی مقاومت
- کد مقاومت SMD (۳/۴ رقمی + EIA-96)
- مقاومت محدودکننده LED
- مقاومت سری زنر
- نزدیک‌ترین E-series

### خازن
- کد خازن سرامیکی / عدسی
- سری و موازی خازن
- انرژی خازن
- ثابت زمانی RC

### سلف
- رنگ سلف
- سری و موازی سلف
- انرژی سلف

### محاسبات مدار
- قانون اهم
- محاسبه توان
- تقسیم‌کننده ولتاژ
- راکتانس خازنی / سلفی
- امپدانس (پایه)

### فرکانس و فیلتر
- فرکانس تشدید LC
- کریستال / اسیلاتور
- فرکانس قطع فیلتر
- طول موج / آنتن

### تغذیه
- دراپ رگولاتور
- عمر باتری
- PWM → ولتاژ

### تراشه
- تایمر ۵۵۵ (Astable / Monostable)
- گین آپ‌آمپ

### دیتاشیت
- جستجوی لینک دیتاشیت قطعات رایج

## چطور APK بسازم؟ (خیلی ساده)

### ۱. نصب Flutter (فقط یک‌بار)

روی کامپیوتر ویندوز / مک / لینوکس:

1. برو به: https://docs.flutter.dev/get-started/install
2. Flutter SDK را دانلود و نصب کن
3. در ترمینال بزن:
   ```bash
   flutter doctor
   ```
4. Android Studio را نصب کن (برای SDK اندروید)

### ۲. باز کردن پروژه

```bash
cd farno_tools
flutter pub get
```

### ۳. ساخت APK

```bash
flutter build apk --release
```

فایل APK اینجا ساخته می‌شود:

```
build/app/outputs/flutter-apk/app-release.apk
```

همین فایل را در کانال تلگرام بگذار.

---

## تست روی گوشی (بدون ساخت APK)

گوشی را با USB وصل کن و USB Debugging را روشن کن، بعد:

```bash
flutter run --release
```
